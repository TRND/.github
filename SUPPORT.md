# Support

## Product and account support

Use the private support channel associated with your TRND product, service, or agreement. If you need help finding the right channel, use the contact listed on the [TRND GitHub profile](https://github.com/TRND) and ask for a private support route.

## Repository support

Authorized team members should use their repository’s established support or maintainer channel for access requests, development questions, and help with assigned work. Keep repository details and work items in their authorized channels.

## What to include

Describe the affected product or feature, what you expected to happen, what you observed, and how we can reach you. Include a version or approximate time if it helps explain the issue. Start with information you are authorized to share. Keep credentials, customer information, private repository links, and unredacted logs out of email and public GitHub posts. Share sensitive evidence only through an agreed private channel.

## Security reports

Use the private reporting routes described in the [security policy](https://github.com/TRND/.github/blob/main/SECURITY.md) for suspected vulnerabilities or security incidents.
