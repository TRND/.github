# Security policy

## Reporting a vulnerability

Use **Report a vulnerability** on the repository’s **Security** tab when it is available. You can also contact a repository maintainer through your existing private support channel. If neither route is available, email [jacob@trnd.co](mailto:jacob@trnd.co), the contact listed on the [TRND GitHub profile](https://github.com/TRND), to request a private reporting channel.

Keep security reports out of public issues, pull requests, and discussions. In your initial report, include the repository or product, affected version or commit, the observed behavior and potential impact, and a way to contact you. Redact credentials, customer information, and other sensitive material from evidence. Send sensitive evidence only through an agreed private channel.

## Scope and disclosure

Follow the repository’s published support policy and any project-specific guidance below. Test only with authorization and limit your work to the minimum needed to document the issue. Coordinate any public disclosure with the maintainers so affected users can be informed and a fix can be made available.

Repository visibility, license terms, and applicable agreements govern access to TRND code and services.
